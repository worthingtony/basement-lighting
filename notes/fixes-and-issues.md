# Fixes and open issues

## Fixes made
- **Virtual DJ wasn't connecting to SoundSwitch (2026-10-20).** SoundSwitch was on BPM Detection as its source; switched to Virtual DJ, it showed "Not connected": SoundSwitch was advertising and listening (OS2L over Bonjour, TCP port picked at launch, e.g. 62885) but Virtual DJ 8.5 never connected. Firewall off. After Tony checked VDJ's OS2L option and macOS **Local Network** permission for both apps, VDJ connected (TCP established to the OS2L port). VDJ's settings.xml still says `os2l = auto`, so the permission or a restart was most likely the fix (not confirmed). Virtual DJ also has Ableton Link open (UDP 20808).
- **Hazer W Haze 141 now runs on DMX (2026-10-20).** A DIP switch was set wrong. For 141 the Antari Z-350 needs DIP **1, 3, 4, 8 ON** (1+4+8+128), the rest OFF. Fan slowing when the wireless dongle is plugged in = DMX has taken over; LED solid amber = DMX mode, flashing amber = making haze. ch1 haze 5-255 = 1-100%, ch2 fan 5-255 = 21-100%. Warm-up about 4.5 min. Manual: `manuals/antari-z-350-fazer-user-manual.pdf`.
- **Scan 110s and Vortex can take color from the Autoloops (2026-10-20).** Custom profiles "Intimidator Scan 110 Claude" and "Vortex Claude" map their colored gobo wheels as color wheels (`notes/gobos.md`), applied with Update Fixtures on Claude-1020. The 110 strobe range is capped at 131.
- **Shocker glowed at idle.** Its 5ch profile left ch 4-5 unmapped, which fired Auto Program. Fixed by moving it from 136 to 417 in 8ch Mode 3 (the unit was re-addressed). **Correction (2026-10-21):** that explanation doesn't fit the guide. In 5-CH, ch4-5 at 0 are "no function", and there is no Auto Program channel in that mode. The move to 8ch did stop the glow, but only because 8ch leaves every zone off, so the panel can't light at all (see Open issues). If the glow comes back in 5-CH, look for a mode mismatch between the unit and the patch first.
- **F4 Scan360 315 did a slow strobe.** The profile's strobe range had R start 8. Changed it to 4 in Fixture Manager, since 4-7 = open. Then File > Save Workspace, then Options > Update Fixtures.
- **F4 lost its name and group** after that profile update. It was renamed "F4 Scan360 315" and set back to Mover Primary Group 2.
- **R1 182 lost its address and mode.** The fixture menu "Reset" was a factory reset. Re-entered 182 / 11CH.
- **L1 149's pool was fuzzy.** A fixture-menu reset fixed it, probably the gobo wheel position.
- **F2 300 was knocked.** Its mirror was hit, so it was reset and re-aimed.
- **Everything was lit with a purple tint.** Unplugging the Control One didn't help. Quitting and relaunching SoundSwitch did.
- **Stock Autoloops never moved the movers.** They had no working position cues. Bank 1 now has cues (see `calibration.md`).
- **Vortex was stuck on one look.** The "Vortex Show" static look runs its built-in program instead.

- **The Shocker (W Shocker 417) can never light in 8-channel mode (found 2026-10-21).** It never came on in any Autoloop, and not in Tony's Autoscripted track either. SoundSwitch's stock profile ("Shocker Panel 180 USB", Chauvet) was read straight out of `SoundSwitchVenues.bin`, where the patched profiles are stored as plain UTF-16 text and numbers. It maps:

  | SoundSwitch mode | Fixture personality | Channels mapped |
  |---|---|---|
  | Mode 1 | 2-CH | ch1 Strobe, ch2 Intensity |
  | Mode 2 | 5-CH | ch1 Intensity, ch2 Strobe, ch3 Shutter |
  | **Mode 3 (ours)** | **8-CH** | **ch5 Auto Program, ch7 Intensity, ch8 Strobe only** |

  In 8-CH, ch1-4 are the four zones: 0-5 = no function, 6-249 = strobe, 250-255 = continuous on. ch8 "Strobe All Zones" only works when ch1-4 are at 6-255. The profile leaves ch1-4 unmapped, so they sit at 0 and every zone is off; the dimmer (ch7) and strobe (ch8) have nothing to act on. Profiles can't hold default values, so the 8-CH mode can't be fixed without mapping the zones.
  - **Fix A:** the 5-CH personality, where ch1 is a plain dimmer for the whole panel (6-255 = 0-100%) and ch2 is strobe speed. Set the Shocker's menu to 5-CH at d417 and its SoundSwitch patch to Mode 2. Stock profile, no Fixture Manager, no Update Fixtures. Loses per-zone control. **Tony turned this down (2026-10-21): he wants to keep 8-CH for the zones.**
  - **Fix B (chosen):** a custom profile that keeps 8-CH and maps the zones. SoundSwitch's own library already has a **newer "Shocker Panel 180 USB"** (`{DA7F9446-...}`, one 8-ch mode) that does exactly this: ch1-4 Strobe (one per zone), ch5 Auto/Sound Active, ch6 Auto/Sound Speed, ch7 Intensity, ch8 Strobe. Its strobe values are in the encrypted part, so it's unknown whether its zones sit open (250-255) at rest. Plan: copy our stock profile (keeps GUID `{9E25F307-...}` and Mode 3, so Update Fixtures applies it to 417), rename it "Shocker Panel 180 USB Claude", and rebuild Mode 3 on that map, giving each zone shutter values (closed 0, strobe 6-249, open 255) so the zones are on whenever the dimmer is up. ch5 and ch6 become attributes, so Attribute Cues can run the panel's built-in zone programs (Auto program 1-8 at 21-180). Try the zones as separate cells only after the single-cell version works.
